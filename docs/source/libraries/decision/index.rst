########
Decision
########

A library for making small, typed decisions with a *decision model* (a
*System One* model such as `Jev`_ or the open-weight `Laya`_): one option out
of a closed set, a yes/no probability, or a position on a rubric. Built for the
branch points of an automation, with a confidence threshold for human hand-off
and an audit log of every decision.

.. _Jev: https://typesafe.ai
.. _Laya: https://github.com/NandhaKishorM/laya
